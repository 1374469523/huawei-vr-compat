# 20-Unreal-集成SDK插件包

原链接：https://developer.huawei.com/consumer/cn/doc/graphics-Guides/app-dev-unreal-plugin-0000001205768073

---

将HuaweiVRSDK包和HuaweiVRController包移入工程Plugins文件夹下，若工程中没有Plugins文件夹，开发者需新建此文件夹。
启动Unreal引擎，打开“菜单 > 编辑 > Plugins”， 取消勾选Built/Virtual Reality下的所有默认选项，选择勾选Virtual Reality/HuaweiVRSDK和Input Devices/HuaweiVRController选项，如下图所示，Restart，即可将SDK Unreal插件包导入到工程中。
