物料说明
需上传的物料主要包括 VR应用封面、VR应用推荐图片、VR应用截图、VR应用全景图四种类型。
VR应用封面:展示在内容库,一个清晰、易识别、稳定的形象会给用户留下深刻的印象，并便于再次寻找。
VR应用推荐图片: 展示在首页，可以有更多的运营性质，激发用户兴趣。
VR应用截图: 展示在应用详情，可以让用户初步了解应用主要场景及价值点，制作精良的应用截图会提升应用的品质感，并进一步促使用户产生下载行为.。这一部分也允许您上传展示视频，因为视频能够生动的展示出应用的故事线并传递更多信息。
VR应用全景图:主要展示在应用详情，相比平面图片可以让用户直接沉浸在您的应用场境中，帮助用户预览场景。
以下就对物料中分层图片和360度全景图片进行详细的说明：
图片分层方法
VR应用封面和VR应用推荐图片由于添加了错层动画和视差动画，前景层和背景层需分层输出、上传。
图片安全区域
视差动效:
在手柄射线悬浮状态时，卡片的背景层会放大至110%，超出卡片的10%区域中的信息将隐藏。
安全区:
由于添加了视差动效，所以卡片边缘10%区域设定为危险区域，而危险区向10%的区域会产生圆角的裁切或者平台统一添加角标，卡片上下边缘20%的区域也不建议放置关键信息，请将Logo和关键信息设计在卡片中心80%的安全区域内。

VR应用全景图
VR应用全景图将会作为环境展示在 VR应用市场的应用详情界面，帮助用户了解预览应用场景。
为了您应用的展示效果,上传的一定是360度图片，不要上传普通2D图片。

应用开发要求
应用能够正确从华为VR Launcher启动，能够正确退出到华为VR Launcher。
对手柄的使用符合HUAWEI VR眼镜体感手柄使用指南。
LOADING界面如果存在，必须是双目的（使用Unity专业版本发布）。
应用申请了存储及手柄权限，需要存储权限进行应用中截图，手柄权限查看androidManifest.xml是否有com.huawei.vrhandle.permission.DEVICE_MANAGER权限。
应用使用时体验流畅，内存峰值不超过1G，使用中外壳温度峰值不超过43度，应用加载及过度界面时间不应超过5s。
应用上传分类选择应用-XX，资质、版权、版号详细规定参见文档：资质审核要求。
