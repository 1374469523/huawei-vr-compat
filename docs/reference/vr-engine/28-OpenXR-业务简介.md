HUAWEI VR Audio Plugin是基于Unity Native Audio框架开发的VR本地音效插件，具有空间音效处理及混响处理功能，能够有效提升VR场景的音效感受。
HUAWEI VR Audio Plugin所有功能均通过Unity GUI进行配置。
