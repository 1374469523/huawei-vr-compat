# 03-使用入门

原链接：https://developer.huawei.com/consumer/cn/doc/graphics-Guides/dev-process-0000001097838308

---

基础知识准备
在使用SDK3.5.0 Unity插件之前，开发者需要对Unity平台及C#语言有一定基础。
开发环境
手机：华为旗舰手机，型号请参见支持的设备
眼镜：HUAWEI VR 2、HUAWEI VR Glass
操作系统：EMUI 10.0及以上版本
Unity版本：5.6.x 至 2019.2.x
开发流程
展开
序号
步骤
说明
1
材料准备
在开发应用前，需要进行以下操作：
在PC端安装Unity平台。
配置相关信息。包括：注册成为开发者、创建应用。
下载 hvrsdk-unity-3.5.0.x 压缩包。
将VR Engine SDK集成到您的开发环境中。
安装华为VR SDK服务APK至手机。
准备好华为手机及华为VR头盔。
2
应用开发
您可以通过集成的HUAWEI VR Engine SDK，完成以下操作：
添加预制件，完成项目构建。
根据您的开发应用的情况，编写详细配置文件。
开始编写您的应用程序逻辑代码。
3
开发后自检
华为提供对应用自动检查的能力。
4
上架申请
开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。
