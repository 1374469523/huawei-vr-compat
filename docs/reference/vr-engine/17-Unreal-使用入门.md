基本知识准备
在使用SDK之前，开发者需要对 Unreal 平台及 C++ 语言有一定基础。
开发环境
手机：华为旗舰手机，型号表可参见支持的设备
操作系统：EMUI10.0及以上版本
Unreal版本：支持4.18、4.19及4.22版本，其中6DoF版本暂时只支持4.22版本

说明
1
材料准备
在开发应用前，需要进行以下操作：
在PC端下载安装Epic Games Launcher。
启动Epic Games Launcher并登陆已经注册的账号。
在Epic Games Launcher的主界面中选中“库”项，并下载对应的Unreal版本。
下载HUAWEI VR SDK For Unreal压缩包。
准备好华为手机及华为VR头盔。手机联网后插入VR2眼镜，会自动提示安装所需VR运行环境，按指引操作即可。
2
应用开发
您可以通过集成的HUAWEI VR SDK For Unreal，完成以下操作：
创建工程以及配置Android环境。
适配VR头盔/眼镜，手柄。
开始编写您的应用程序逻辑代码。
3
开发后自检
华为提供对应用自动检查的能力。
4
上架申请
开发完成后需要在AppGallery Connect中将应用信息补充完整并提交上架申请。
